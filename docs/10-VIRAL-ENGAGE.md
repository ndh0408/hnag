## 2. The 5 Viral Loops (Engineered)

### LOOP 1 — Group Decision Loop (k = 0.85 target)

**Pain:** "Mọi người muốn ăn gì?" 5 người cãi 20 phút.

```
User opens Group Vote
       ↓
Invites 4 friends via Zalo link
       ↓ (3 are not on app yet)
3 friends install to vote
       ↓
Voting happens, decision made
       ↓
1.5 of those 3 retain weekly
       ↓
Each retained user later invites 2.3 more on average
```

**Mechanics:**
- One-click invite (Zalo, Messenger, system share)
- Web vote landing page (no install required) → CTA to install for "save your taste"
- Post-vote: "Lưu nhóm này lại cho lần sau?" CTA
- Re-engagement: "Anh em mời nhóm vote lại tuần này?"

**Friction reducers:**
- Phone number lookup auto-suggests friends
- Voting works on web without account
- 1 tap "Set as default group" — keep coming back

**Measurement:**
- k-factor weekly
- Group LTV (groups outlast individuals)
- % new users via group invite

### LOOP 2 — Content Loop (k = 0.45)

```
User shoots food video
       ↓
Auto-edits with HNAG style (3 templates)
       ↓
Shares to TikTok/Insta/Zalo with watermark
       ↓
External viewers see "via Hôm Nay Ăn Gì?"
       ↓
QR code in watermark → install
       ↓
New user signs up
```

**Mechanics:**
- In-app creator tools (filters, music, food stickers)
- Auto-watermark (creator credit + HNAG branding)
- Cross-post tools (TikTok, Insta, Zalo, Facebook)
- Hashtag campaigns (#HôNayAnGì)

**Quality boost:**
- AI auto-enhances food shots (color grade)
- Auto-captions in VN
- Templates: "Day-in-my-mouth", "Hidden gem find", "Recipe challenge"

### LOOP 3 — Couple/Pair Loop (k = 0.95, highest!)

```
User links partner account
       ↓
2x retention vs solo
       ↓
Together: order more, save more, plan more
       ↓
Anniversary feature → social posts
       ↓
Friends see → curious → install
```

**Mechanics:**
- Partner finder via phone book
- "Tag couples" social trend
- Anniversary auto-recaps shareable to social
- Date night planning shareable

**Lock-in:** Breaking the link = breaking the data treasure. Strongest churn defense.

### LOOP 4 — Reaction Loop (k = 0.30, but cheap)

```
User reviews quán
       ↓
Friends notified (push)
       ↓
Friends see review → drives discussion
       ↓
Friends comment → drives notifications
       ↓
Engagement multiplies
```

**Mechanics:**
- Reviews push to all relevant friends
- Comment threads
- Reaction emoji (food-themed: 🍜🤤🔥💯)
- "First to try" badges

### LOOP 5 — Challenge Loop (k = 0.40, viral spikes)

```
Branded challenge launches (e.g. "30 Phở Tháng 11")
       ↓
Top creators participate, post → external reach
       ↓
Followers join challenge → install required
       ↓
Leaderboard creates competition
       ↓
Winners get prize + social bragging
```

**Mechanics:**
- 1 mega-challenge per month
- 4 micro-challenges per week
- Sponsored challenges = revenue
- Leaderboards by city, country
- Hall of Fame profile badges

## 3. The 7 Daily Hooks (Retention)

Each user gets 1–3 of these per day based on persona + behavior.

**Goal:** Open + view 1 card

### Hook 2 — Lunch Decide (11:30am)
**Trigger:** Time + location (office hours)
**Behavior:** 3 quick suggestions, one-tap order
**Conversion:** ~12% click-through (high)

### Hook 3 — TikTok Trending Push (variable)
**Trigger:** AI detects new viral dish in user's city
**Copy:** "Món bánh tráng cuốn đang viral 2.4M views, có 5 quán gần bạn"
**FOMO factor:** ★★★★★

**Trigger:** Evening + couple/family context
**Copy:** "Vợ chồng nay ăn gì? Hà có 3 quán hợp 2 người"

**Trigger:** Streak about to break
**Copy:** "Còn 4 tiếng giữ streak 12 ngày! Quyết nhanh nha 🔥"

**Trigger:** Friend reviewed / liked / commented
**Copy:** "Mai vừa review Phở Lý Quốc Sư — xem thử"

### Hook 7 — Late Night Snack (10:30pm)

## 4. In-App Engagement Hooks (Pull users back in-session)

### 4.1 The Endless Scroll Engineered

```
Home feed (mostly horizontal sections)
       ↓
After section 3, "Stay tuned" full-bleed video card
       ↓ (autoplay grabs attention)
Scroll continues
       ↓
"Bạn đã xem 3 phút. Continue?" reset prompt (after 5 min)
       ↓
```

### 4.2 Daily Rewards (Variable Reward Loop)

Open app every day:
- Day 1: 10 XP
- Day 3: 30 XP + sticker

- Day 14: badge + voucher partner
- Day 30: special badge + premium discount
- Day 100: "Foodie Centurion" exclusive badge

- "Comment trên 1 review" → 15 XP
- "Khám phá 1 quán mới gần bạn" → 25 XP
- "Vote trong nhóm" → 20 XP

Random quest each day (avoid habituation).

### 4.4 Daily Random Wheel
Once-a-day spin for:
- Free premium day (rare)
- Voucher partner
- Bonus XP
- "Mystery box" (could be anything)

Lottery mechanic — high open rate.

### 4.5 Live Activities (iOS Dynamic Island)

User always sees something live:

→ Lockscreen presence = brand presence.

## 6. Notification Strategy (Anti-Fatigue)

### 6.1 ML-driven Send Timing

Per user, learn:
- Best hour to push (when they open most)
- Best content type (food vs social vs streak)
- Quiet hours (no push)

**Implementation:** Multi-armed bandit per user.

### 6.2 Frequency Capping

- Total push/day: ≤ 5 (free), ≤ 3 (paying — value of fewer interruptions)
- Per category cap (social: 2, AI: 2, system: 1)
- Smart compression: if 3 friend events, send 1 digest

### 6.3 Content Personalization

```python
def personalize_push(user, push_template):
    # Pick variant based on user's reply history
    variant = bandit.select(user.id, template.variants)
    
    # Fill content with user-specific data
    return template.fill(
        food=user.likely_next_food(),
        restaurant=user.nearest_open(),
        budget=user.remaining_budget(),
        mood=user.inferred_mood()
    )
```

### 6.4 Smart Bundling

Multiple events → 1 push:
- 5 friends posted → "Mai và 4 người khác vừa review"
- Order updates → consolidated "Đơn hàng đến trong 5 phút"

### 6.5 Re-engagement Pushes

Inactive 3 days:
- Day 3: "Hà nhớ bạn 🥺 Quán bún chả gần bạn vừa update"
- Day 7: "Bạn bè đã review 12 món tuần này — xem thử?"
- Day 14: "Voucher 30% sắp hết hạn 🎁"
- Day 30: Final push + email + push "Comeback prize"

After 60 days no activity → soft-deletion warning, then archived.

## 8. The TikTok-Style Feed (Engagement DNA)

### 8.1 What makes TikTok addictive (apply here)

| TikTok mechanic | HNAG adaptation |
|-----------------|-----------------|
| Instant value (video plays immediately) | Card autoplay, 0.4s first-frame |
| Vertical scroll, low friction | Card stack swipe |
| Infinite content | Endless feed sections |
| AI personalization (Tongren) | Two-tower + Taste vector |
| Sound on, immersive | Optional sound, ambient food sounds |
| Quick interaction (like, share) | Save, like, share, order |
| Creator-driven | Creator program |
| Algorithm-driven discovery | Hidden Gems section, AI Pick |
| Variable rewards | Random Wheel daily, surprise badges |
| Social validation | Friend signals, reviews verified |

### 8.2 Feed Engagement Tactics

**A. Auto-play sound on tap**
- One tap = sound on (most users want it)
- "Audio: bowl pouring noodles" — sensory hooks

**B. Endless variety**
- Never see same item twice within 24h
- Cuisine cycle: max 2 in a row, then switch
- Action mix: cook/order/dine spread

**C. Surprise drops**
- 1 in 20 cards is "🎁 Unexpected gem" — different vibe
- Editorial inject (curated by team)

**D. Time-of-day awakening**
- Morning: bright, light foods
- Afternoon: energizing, snacks
- Evening: family, hearty
- Late night: comfort, snack

### 8.3 Creator Tools (Make Content Effortless)

- 1-tap food photo enhance (AI grade)
- 5-second video editor (cut, add music)
- Recipe template generator (from photo + AI write-up)
- Caption AI generator
- Hashtag suggestion

**Goal:** Lower creator friction → more content → richer feed.

## 13. Churn Prevention

### 13.1 Churn Prediction Model

Features:
- Days since last open
- Decline in session count
- Cancelled subscription before
- Negative feedback signals
- Friends churned (contagion)

Output: churn probability next 30 days.

### 13.2 Intervention Ladder

| Risk | Action |
|------|--------|
| Low (5–20%) | Normal push |
| Medium (20–40%) | Personalized win-back push |
| High (40–70%) | Email + Zalo + discount voucher |
| Critical (>70%) | "We miss you" outreach + premium 1 month free trial |

### 13.3 Subscription Cancel Flow

When user clicks Cancel:
1. "Are you sure?" with personalized cost-save value ("You've saved 240k this month")
2. Survey: "Why?"
3. Offer based on reason:
   - "Too expensive" → 50% off 3 months
   - "Not using enough" → Pause 1–3 months
   - "Missing feature X" → Roadmap reveal
4. Final: confirmed cancel + offboarding

**Save rate target:** 25% of cancels.
