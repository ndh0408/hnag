## 1. Viral Growth Strategy

### 1.1 The Three Viral Loops

#### Loop A — Social Decision Loop (highest ROI)
```
User opens app → can't decide alone → creates Group Vote → 
shares link via Zalo/Messenger → 4 friends install to vote → 
2 stay → each invites others later
```
- **Viral coefficient (k):** target 0.6 by Y2, 1.1 by Y3
- **Activation:** Group voting requires app install (no web fallback)
- **Friction:** lowered via "join as guest, save by signup"

#### Loop B — Content Loop (TikTok-style)
```
User posts food video → shared off-platform with watermark → 
viewer sees @username + link → installs to follow
```
- Distinctive watermark: "Made on Hôm Nay Ăn Gì?" + QR
- Auto-export to TikTok/Reels with branded sticker
- Creator royalty system to incentivize quality

#### Loop C — Couple Loop (highest retention)
```
User invites partner → both link accounts → couple-only features 
unlock → both retained because leaving = breaking the link
```
- Couple Mode: 2x retention vs solo users
- Anniversary memory book gamifies
- Hard to churn — emotional sunk cost

### 1.2 Referral Program
- "Mời bạn → cả 2 nhận 1 tháng premium miễn phí"
- Tier rewards: 5 refs → physical Foodie tote bag, 20 refs → premium 1 năm
- Trackable via Branch.io deep links
- Anti-fraud: device fingerprint + behavior check

### 1.3 Launch Tactics

**Pre-launch (Month -3 to 0):**
- Waitlist landing page với gamification (skip queue by sharing)
- Target 100K signups before app launch
- Tease via TikTok creator partnerships (10 micro-creators)

**Launch (Month 0–3):**

- "TikTok Food Decision Challenge" branded hashtag
- Press: VnExpress, Tuổi Trẻ, Genk, ICTNews

**Growth (Month 3–12):**
- Performance marketing scale: TikTok, Facebook, Zalo
- Branded content with creators
- University ambassador program (50 schools)
- Office "lunch decision" partnerships (free premium for HR teams)
- Cinema/Metro/coffee shop offline placements

## 2. TikTok-style Retention Strategy

### 2.1 Daily Hooks (Why open the app every day)

| Hook | Mechanic | Target action |
|------|----------|---------------|
| 🌤 **Morning Pull** | Push 7:30am: weather-based suggestion | Open + see card |
| 🍽 **Lunch Decide** | Push 11:45am: 3 fast options | Tap order |
| 🌙 **Evening Companion** | Push 7pm: "vợ/chồng/người yêu nay ăn gì?" | Open + decide |
| 🔥 **Streak Reminder** | Push 9pm if streak about to break | Quick decide |
| 📱 **TikTok-style feed** | Endless scrollable video food content | Browse 8min+ |
| 🎲 **Daily Random** | Lottery-style daily food (chance for free voucher) | Open once/day |
| 🏆 **Leaderboard refresh** | Weekly champion announcement | Engagement compete |

### 2.2 Habit-Building Design (BJ Fogg's Tiny Habits)

```
Trigger (push/notification at peak hunger time)
   ↓
Ability (1 swipe to decide — lowest friction)
   ↓
Motivation (food photo + AI reason hits dopamine)
   ↓
Reward (variable: discount, badge, social comment, recipe)
   ↓
Investment (save, review, share → sunk cost ↑ retention)
```

### 2.3 Retention Metrics & Targets

| Metric | Day 1 | Day 7 | Day 30 | Day 90 |
|--------|-------|-------|--------|--------|
| Retention (free) | 65% | 35% | 22% | 14% |
| Retention (premium) | 95% | 80% | 70% | 60% |
| Retention (couple-linked) | 92% | 78% | 65% | 55% |
| DAU/MAU ratio | — | — | 32% | 35% |

### 2.4 Anti-Churn Tactics

- **Predictive churn model:** flag users not opening 3 days → personalized win-back push
- **Win-back email:** "Tuần qua bạn vắng — Hà nhớ bạn 🥺 Đây là món hợp bạn nhất tuần này"
- **Exit survey** if uninstall (Android) or unsubscribe → feed product
- **Cancel flow** for premium: offer 50% off OR pause subscription 1–3 months
- **Re-engagement after 7+ days:** auto-discount voucher from partner

### 2.5 Engagement Loops (in-app)

- **Story bar** auto-shows new content
- **For You feed** — infinite, personalized
- **Comments** drive return ("Mai replied to your review")
- **Live cooking sessions** (V2) — community events
- **Daily check-in widget** (Live Activities on iOS)
